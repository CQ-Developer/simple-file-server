# Simple File Server

A lightweight file management service supporting upload, download, delete, and
paginated search. Built with Spring Boot 4.1.0 on Java 25.

## Tech Stack

Java 25, Spring Boot 4.1.0, Gradle (Kotlin DSL), PostgreSQL, Hibernate JPA,
Docker (eclipse-temurin:25-jre-alpine)

## Quick Start

### Docker Compose (Recommended)

```bash
docker compose --env-file docker/.env -f docker/docker-compose.yaml up -d
```

### Local Build

Prerequisites: JDK 25, PostgreSQL

```bash
./gradlew bootJar
java -jar build/libs/simple-file-server-0.0.1-SNAPSHOT.jar
```

## API Reference

### Base Path

All API paths are prefixed with `/sfs`. Full request URL format:

```
http://{host}:{port}/sfs/api/...
```

### Authentication

#### Form Login

Default form login endpoint `/sfs/login`. The login page is auto-generated by Spring Security.

#### Logout

```
POST /sfs/logout
```

No additional parameters required. The server invalidates the current session.

#### Authentication Error Responses

| Scenario | HTTP Status | Response Body |
|---|---|---|
| Unauthenticated (no valid credentials) | `401 Unauthorized` | `{"success": false, "message": "Invalid username or password"}` |
| Insufficient permissions (authenticated but unauthorized) | `403 Forbidden` | `{"success": false, "message": "Insufficient permissions"}` |

### API Endpoints

#### Upload File

**Upload one or more files.**

```
POST /api/upload
```

**Authorization**

| Field | Value |
|---|---|
| Auth required | Yes |
| Authority | `sfs:file:upload` |

**Request**

- **Content-Type:** `multipart/form-data`
- **Body:**

| Field | Type | Required | Description |
|---|---|---|---|
| `files` | `multipart[]` | Yes | File list to upload (max 10 files) |

**Response Example**

```json
{
  "success": true,
  "message": "ok",
  "data": null
}
```

**Constraints**

- Max **10 files** per request
- Max **1 GB** per file, **10 GB** total request size

#### Download File

**Download a file by UUID.**

```
GET /api/download/{id}
```

**Authorization**

| Field | Value |
|---|---|
| Auth required | Yes |
| Authority | `sfs:file:download` |

**Path Parameters**

| Parameter | Type | Description |
|---|---|---|
| `id` | `UUID` | File unique identifier |

**Response**

- **Content-Disposition:** `attachment; filename="{filename}"` (UTF-8 encoded)
- **Content-Type:** Auto-detected media type
- **Content-Length:** File size in bytes
- **Body:** Binary file stream

**Error Response**

File not found:

```json
{
  "success": false,
  "message": "File not found"
}
```

#### Delete File

**Delete a file by UUID.**

```
DELETE /api/delete/{id}
```

**Authorization**

| Field | Value |
|---|---|
| Auth required | Yes |
| Authority | `sfs:file:delete` |
| Extra constraint | Only the uploader can delete |

**Path Parameters**

| Parameter | Type | Description |
|---|---|---|
| `id` | `UUID` | File unique identifier |

**Response Example**

```json
{
  "success": true,
  "message": "ok",
  "data": null
}
```

#### List Files

**Paginated file listing with optional name search.**

```
GET /api/files
```

**Authorization**

| Field | Value |
|---|---|
| Auth required | Yes |
| Authority | Any authenticated user |

**Query Parameters**

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `name` | `string` | No | — | Filename keyword (LIKE `%name%` fuzzy match) |
| `page` | `integer` | No | `1` | Page number (1-indexed) |
| `size` | `integer` | No | `10` | Records per page |

**Response Example**

```json
{
  "success": true,
  "message": "ok",
  "data": {
    "pages": 3,
    "records": [
      {
        "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
        "name": "photo.jpg",
        "hash": "abc123def456...",
        "size": 1048576,
        "uploader": "admin",
        "uploadTime": "2026-07-08T10:30:00"
      }
    ]
  }
}
```

### Security & Permissions

#### Permission Mapping

| Endpoint | Required Authority |
|---|---|
| `POST /api/upload` | `sfs:file:upload` |
| `GET /api/download/{id}` | `sfs:file:download` |
| `DELETE /api/delete/{id}` | `sfs:file:delete` |
| `GET /api/files` | Any authenticated user |

### Response Models

#### Generic Response

```json
{
  "success": true,
  "message": "ok",
  "data": null
}
```

| Field | Type | Description |
|---|---|---|
| `success` | `boolean` | Whether the operation succeeded |
| `message` | `string` | Response message (`"ok"` on success, error description on failure) |
| `data` | `any` | Response data, may be `null` |

#### Paginated Response

```json
{
  "pages": 3,
  "records": []
}
```

| Field | Type | Description |
|---|---|---|
| `pages` | `integer` | Total number of pages |
| `records` | `array` | Records of the current page |

#### File Record

```json
{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "name": "photo.jpg",
  "hash": "abc123def456...",
  "size": 1048576,
  "uploader": "admin",
  "uploadTime": "2026-07-08T10:30:00"
}
```

| Field | Type | Description |
|---|---|---|
| `id` | `UUID` | File unique identifier |
| `name` | `string` | File name |
| `hash` | `string` | SHA-256 file hash |
| `size` | `number` | File size in bytes |
| `uploader` | `string` | Uploader username |
| `uploadTime` | `string` | Upload time (ISO-8601 format) |

### Error Handling

#### Business Errors

All business errors are returned with HTTP 200 + `success: false`.

| Scenario | HTTP Status | `success` | `message` |
|---|---|---|---|
| Business exception | `200 OK` | `false` | Specific error description |
| Missing request parameter | `200 OK` | `false` | `"Missing form data"` |
| Unsupported request method | `200 OK` | `false` | `"Unsupported request method"` |

#### Security Errors

| Scenario | HTTP Status | Response Body |
|---|---|---|
| Unauthenticated | `401 Unauthorized` | `{"success": false, "message": "Invalid username or password"}` |
| Insufficient permissions | `403 Forbidden` | `{"success": false, "message": "Insufficient permissions"}` |
